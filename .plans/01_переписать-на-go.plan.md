# План: Переписать letsencrypt-certificate с Python на Go

## Статус: ГОТОВО

## Цель
Переписать Python-утилиту (~1650 строк) на Go — получить единый статически слинкованный бинарник без зависимости от Python-рантайма, с минимальным набором внешних зависимостей.

---

## Зависимости

**Единственная внешняя зависимость:**
- `golang.org/x/crypto` — содержит `acme` (ACME v2 клиент) и `ssh` (SSH/SCP)

**Всё остальное — стандартная библиотека Go (1.21+):**
- `net/http` — NIC.RU API, Telegram
- `encoding/xml` — парсинг XML от NIC.RU
- `encoding/json` — кеш OAuth токена
- `net` — DNS TXT проверка через `net.Resolver` с кастомным `Dial`
- `crypto/rsa`, `crypto/x509`, `encoding/pem` — ключи и CSR
- `log/slog` — структурированное логирование
- `crypto/tls` — проверка SSL сертификатов

## Формат config.ini

Синтаксис в стиле git-config: `[section]` и `[section "name"]` для именованных блоков.

```ini
[log]
file = /var/log/letsencrypt-certificate/app.log

[notifier.telegram]
token     = 123456:ABC-DEF...
recipient = -100123456789

[acme]
directory_url = https://acme-v02.api.letsencrypt.org/directory
email         = admin@example.ru

[nic]
app_login    = myapp
app_password = secret
username     = myuser
password     = secret
service      = myservice
domain       = example.ru

[dns]
check_interval_sec = 300
check_max_attempts = 60

[certificate "my-server"]
domains        = example.ru
ports          = 443
deploy_type    = local
private_path   = /etc/apache2/ssl/private.pem
fullchain_path = /etc/apache2/ssl/fullchain.pem
commands       = sudo systemctl restart apache2

[certificate "remote-nginx"]
domains        = www.example.ru, example.ru
ports          = 443
deploy_type    = ssh
ssh_host       = 10.0.0.1
ssh_username   = admin
ssh_key_path   = keys/id_rsa
ssh_private_path   = /etc/nginx/ssl/private.pem
ssh_fullchain_path = /etc/nginx/ssl/fullchain.pem
commands       = killall nginx, nginx

[certificate "mail"]
domains        = mail.example.ru
ports          = 465, 993
deploy_type    = ssh
ssh_host       = 10.0.0.2
ssh_username   = admin
ssh_key_path   = keys/id_rsa_mail
ssh_private_path   = /etc/postfix/ssl/private.pem
ssh_fullchain_path = /etc/postfix/ssl/fullchain.pem
commands       = sudo systemctl restart postfix, sudo systemctl restart dovecot
```

**Правила парсера:**
- `#` и `;` — комментарии
- `[section]` — простая секция
- `[section.subsection]` — секция с подсекцией через точку (для notifier.telegram, notifier.slack и т.д.)
- `[section "name"]` — именованная секция (для множественных сертификатов)
- `key = value` — пара, пробелы вокруг `=` игнорируются
- Запятая — разделитель для списков (`domains`, `ports`, `commands`)

## Критерий готовности

```bash
# Собирается без ошибок и предупреждений
go build -o letsencrypt-certificate ./cmd/...
go vet ./...

# Статичный бинарник (без CGO)
CGO_ENABLED=0 go build -o letsencrypt-certificate ./cmd/...

# Запускается
./letsencrypt-certificate --config config.ini.example --help
```

Функционально: успешно получен сертификат в staging-режиме (`https://acme-staging-v02.api.letsencrypt.org/directory`).
