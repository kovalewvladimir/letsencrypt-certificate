# План: Новые CLI-флаги -list и -certs

## Статус: ГОТОВО

## Цель
Добавить два флага в `cmd/main.go`: `-list` для вывода имён всех сконфигурированных сертификатов, и `-certs` для выборочного запуска только указанных сертификатов.

## Шаги

- [x] Шаг 1: Добавить флаг `-list` (bool) в `cmd/main.go` рядом с существующими флагами (строка ~29)
- [x] Шаг 2: Добавить флаг `-certs` (string) в `cmd/main.go` рядом с существующими флагами (строка ~30)
- [x] Шаг 3: После загрузки конфига (строка ~43) добавить обработку `-list`: вывести имена всех сертификатов (`cfg.Certificates[i].Name`) и вызвать `os.Exit(0)`
- [x] Шаг 4: После обработки `-list` добавить обработку `-certs`: распарсить строку через `strings.Split`, найти совпадения по `Name`, вывести ошибку для не найденных, заменить `cfg.Certificates` отфильтрованным срезом
- [x] Шаг 5: Обновить `config.ini.example` — добавить комментарий с примерами использования новых флагов

## Критерий готовности
```
# Список всех сертификатов без запуска:
./letsencrypt-certificate -config config.ini -list

# Запуск только двух конкретных сертификатов:
./letsencrypt-certificate -config config.ini -certs "example.com,test.org"

# Ошибка при указании несуществующего имени:
./letsencrypt-certificate -config config.ini -certs "nonexistent"
# → выводит ошибку и завершает с ненулевым кодом
```

Нет — изменения только в `cmd/main.go`, дополнительные пакеты не нужны (все нужные уже импортированы: `fmt`, `os`, `strings`).
